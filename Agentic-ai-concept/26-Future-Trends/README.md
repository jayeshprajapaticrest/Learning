## Scope (what this section will cover)
Forward-looking, with strict **`[Established]` / `[Emerging]` / `[Speculative]`** labeling so you can tell
shipping reality from roadmap from hope.
- **Agent interop protocols:** **A2A (Agent-to-Agent)** and the standardization landscape; agent registries
  & discovery; how MCP + A2A compose. `[Emerging]`
- **AI operating systems / agent runtimes:** the OS metaphor — scheduling, memory, permissions for agents. `[Emerging/Speculative]`
- **Cognitive architectures:** longer-horizon memory, world models, neuro-symbolic hybrids. `[Emerging]`
- **Self-improving agents:** experience/skill libraries, learned tools, RL-from-deployment. `[Emerging, with caveats]`
- **Autonomous organizations / multi-agent economies.** `[Speculative]`
- **Standards & governance trajectory:** regulation (EU AI Act), assurance, agent identity standards. `[Emerging]`
- **What probably *won't* change soon** — and how to build durably amid churn.

## Key questions it answers
- Which emerging trends should influence architecture decisions *today*, and which to just watch?
- How do A2A, agent registries, and "agent OS" ideas fit the model in this guide?
